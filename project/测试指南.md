## 运行方式

### 本地直接运行

```bash
cd project
pip install -r ../requirements.txt
python run_demo.py
```

脚本会读取匹配表、处理 CSV，并打印每个分类金额与核验结果。

### 影刀中调用

```python
import expense_breakdown

result = expense_breakdown.main(匹配名称字典)
summary = result['summary']   # {分类名: 金额}
total = result['total']       # 总金额
```

## 常见问题

### Q: `ModuleNotFoundError: No module named 'xbot'`

`expense_breakdown.py` 已对 `xbot` 做 ImportError 兜底，脱离影刀时使用标准 `logging`，无需额外安装。

### Q: 金额有几分钱误差

源数据用 `float` 累加，末位可能有 `1e-10` 级误差。核验时按 `abs(diff) < 0.01` 判断即可。

### Q: 某个分类金额对不上

1. 看日志中的“未匹配”行数是否为 0
2. 对照匹配表的分类名称，确认是否新增了编码或业务名称
3. 新增编码若与已有分类文字相同，会自动走第二层文字匹配；否则需要在 `match_special_rules` 中补规则

### Q: 如何换一个月的数据

替换 `作业素材/源文件/` 下的 CSV，或在调用时传入 `csv_path`：

```python
expense_breakdown.main(规则字典, csv_path=r'D:\data\202601.csv')
```
